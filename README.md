# 보증금지킴이

이사 후 놓치기 쉬운 전입신고 · 확정일자 · 전월세 신고 마감일을 한 번에 확인하고,
필요 서류와 공식 사이트까지 안내해주는 프론트엔드 서비스입니다.

## 주요 기능

- 이사 정보(전입일 · 계약 체결일 · 보증금/월세 · 신규/갱신 여부) 입력 폼
- 전입신고 마감일, 확정일자 권장일, 전월세 신고 대상 여부와 마감일을 D-day와 함께 자동 판정
- 절차별 필요 서류 체크리스트 (로컬 저장으로 진행 상태 유지)
- 정부24 · 인터넷등기소 · 국토부 전월세신고 시스템 바로가기
- 마감일 구글 캘린더 추가 (.ics 내보내기)
- 헷갈리는 용어(대항력, 우선변제권 등) 툴팁
- 놓쳤을 때 예상 과태료 계산기
- 자주 묻는 질문(FAQ)

## 개발

```bash
npm install
npm run dev      # 개발 서버 실행
npm run build    # 프로덕션 빌드
```

## 기술 스택

React + TypeScript + Vite. 별도 백엔드 없이 브라우저 로컬 저장소만으로 동작합니다.

## 안내

본 서비스에서 제공하는 신고 기한 · 과태료 정보는 법령을 바탕으로 한 참고용 안내이며 법적 효력이 없습니다.
정확한 내용은 정부24, 국토교통부, 관할 주민센터 등 공식 기관을 통해 반드시 다시 확인해주세요.
